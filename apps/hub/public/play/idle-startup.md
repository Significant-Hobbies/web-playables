# Idle Startup

Canonical: https://idle.aliveville.com/play/idle-startup/

Idle Startup is the retained playable result of the Web Playables research lab.

## How it works

Ship product features, hire a team, raise funding rounds, and improve a simulated startup over time. The deterministic simulation continues through offline progress and resumes from a versioned local save.

## Access and privacy

The game is publicly playable without an account or installation. Saves stay in the local gamekit persistence layer; no private player state is part of public discovery.

## Distribution proof

The same game code builds for a normal browser deployment and a submission-ready YouTube Playable package through platform adapters.

Ship features. Hire the team. Raise the round.
