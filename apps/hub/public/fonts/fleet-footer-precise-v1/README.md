# Footer fonts

Exact OFL-licensed local Geist, Geist Mono and Newsreader WOFF2 assets from the owner-selected Precise study. Source URLs, axes, hashes and license filenames are in provenance.json. The three OFL files accompany their fonts. No subsetting or renaming of font binaries; Fleet family names are CSS aliases only. The hub publishes these files under `/fonts/fleet-footer-precise-v1/` and points the footer's `font-base` there. Browser loading and external-request behavior have not been verified.
