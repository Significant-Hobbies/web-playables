About this browser build

The original Godot game now runs in your browser. Its twelve-encounter story, battles, companions, chest and short combat animations are preserved. It is a prototype, best on a larger screen in landscape. Browser saves are separate from native saves. Private browsing, storage restrictions or clearing site data can remove progress. Export a backup before clearing storage. This game is outside the YouTube Playables lane.
